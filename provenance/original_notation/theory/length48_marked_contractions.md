# Marked contractions at length 48

Let Y be a 48-point unital support of affine dimension eight. Pair averaging
gives a direction with at most four complete fibres, since
`binomial(48,2)/(2^8-1)=1128/255<5`. Its singleton core has length
`48-2N`. The complete low-dimensional Reed-Muller census excludes lengths
42 and 46 in the seven-dimensional quotient, so only `N=0,2,4` remain.

For N at most three the core spans the quotient, by the deletion-kernel
argument in `space_classification.md`. For N=4 the length-40 core can have
intrinsic affine dimension six or seven. Both possibilities must be included.
The full source domain is therefore:

| Core length | Core affine dimension | Complete fibres | Core classes |
|---:|---:|---:|---:|
| 48 | 7 | 0 | 98 |
| 44 | 7 | 2 | 35 |
| 40 | 6 | 4 | 1 |
| 40 | 7 | 4 | 18 |

There are 152 core classes. Every compatible fibre set and graph-label
solution is generated by the degree-two linear system in the general
inverse-contraction construction. Quotienting graph labels by affine
functions is an affine shear of the complete lifted support.

## Marked-core symmetry

The complete affine stabiliser of the core acts on compatible fibre sets.
For each fibre-set orbit, its stabiliser acts affinely on the graph-label
quotient. Schreier generators describe this latter action exactly. Taking
one representative of each resulting orbit preserves a complete cover of
the unmarked supports. The final quotient is still by the full affine group
in eight dimensions: marked-core orbits are not final space classes.

For a six-dimensional core embedded in the hyperplane `u=0`, every ambient
stabiliser has the form

```text
(x,u) -> (A x + b + u v, u),
```

where `(A,b)` stabilises the intrinsic core and `v` is any six-bit vector.
Thus the full ambient stabiliser has order `64*|Aut_aff(C)|`. Its generators
are the intrinsic generators extended to fix u, together with the six maps
`x_i -> x_i+u`. This includes the pointwise stabiliser of the core, which
would be lost if one used only its intrinsic automorphisms.

A marked support with a proper-span core need not span all eight dimensions.
The emitted representatives are therefore filtered by their exact affine
rank. This is legitimate after the marked quotient because rank is invariant
under every affine map used in that quotient. For a spanning core and N>0,
the full fibre already ensures the eighth direction. For N=0, exactly the
zero affine-label coset is removed.

## Finite domain

The complete source profiles give 422,425,662 label/fibre pairs after
removing the affine N=0 graphs. Of these, 43,524,096 have insufficient affine
rank; all lie in the proper-span core family. The remaining 378,901,566
pairs reduce to 856,098 full-rank marked representatives. The proper-span
family itself has 140 marked orbits, of which 42 have full rank.

The exact full-affine quotient has 9,868 classes in 9,845 invariant buckets;
21 buckets split into multiple classes. Every marked representative is
assigned by an explicit affine map, and the independently recomputed
codeword-incidence canonical forms separate all final classes. The
certificate `certificates/c48_marked_space_census.json` binds this complete
domain to the stored dimension-eight catalogue. Its standalone replay also
regenerates all marked orbits from the complete core domain.

`prepare_c48_marked_inputs.py` obtains the core supports and their full
stabilisers from the independently certified affine base, and checks fibre
counts using two different exact formulas. `enumerate_c48_marked_spaces.py`
checks the output ranks, moments, contractions and marked-orbit accounting.
`quotient_c48_marked_spaces.py` uses the configured exact affine transporter,
replays every positive map, and independently canonicalises the final
representatives through their complete codeword-incidence graphs.

```text
python code/prepare_c48_marked_inputs.py --output work/c48_inputs
python code/space_native/build.py --build-dir build/spaces --select c48_m08_marked_orbits
python code/enumerate_c48_marked_spaces.py --inputs work/c48_inputs --native build/spaces/c48_m08_marked_orbits --output work/c48_marked
python code/space_native/generic/build.py --length 48 --dimension 8 --build-dir build/finite
python code/quotient_c48_marked_spaces.py --generated work/c48_marked --native-directory build/finite --graph-native build/affine_codeword_graph --work-directory work/c48_quotient --output work/c48_census.json
python code/verify_c48_marked_space_census.py --native-directory build/finite --graph-native build/affine_codeword_graph --marked-native build/spaces/c48_m08_marked_orbits --work-directory audit/c48 --output certificates/c48_marked_space_census.json
```
