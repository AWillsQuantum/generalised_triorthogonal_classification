# Protocol witnesses and output equivalence

Write a binary matrix as `G = [G_1; G_0]`, with `q` logical rows and `h`
stabiliser rows. Its length is its number `n` of columns and its ordinary
space footprint is `S=q+h`. All logical rows are counted throughout.

The matrix must have full row rank and distinct complete columns. Every
overlap of one, two or three rows containing a stabiliser row is even.
Repeated row indices add no new conditions, since squaring a binary entry
does not change it. The overlaps involving only logical rows specify a
symmetric trilinear tensor `tau` obeying `tau(x,x,y)=tau(x,y,y)`.

## Exact distance and error coefficient

The distance is the smallest weight of a binary vector `v` satisfying
`G_0 v=0` and `G_1 v != 0`. The leading error coefficient counts all such
vectors of exactly that minimum weight, counting a vector once regardless
of which nonzero logical syndrome it produces.

The reference verifier computes this using a minimum-weight subset dynamic
programme. For each complete column syndrome `s`, retain the minimum weight
of a subset with XOR `s`, and the number of subsets of that weight. Appending
a column `g` replaces a state by the better of its old value and the value
at `s xor g` plus one; equal weights add counts. The two subsets classes
(excluding or including this column) are disjoint. Induction on the number
of columns proves both the weights and counts exactly.

In the coordinate convention used here, the lowest `q` syndrome bits are
logical. At the end take the minimum over `1 <= s < 2^q` and sum the counts
attaining it. Thus no weight cutoff or heuristic enters the witness distance
calculation. The reference implementation has a memory guard at 22 rows;
all distributed witnesses lie below that guard.

## Intrinsic output and CNOT+S equivalence

The radical is the kernel of the linear map `u -> tau(u,-,-)`. An output is
intrinsic when this kernel is zero. The verifier tests the contraction matrix
for every nonzero `u`; it must have nonzero rank.

Degenerate logical outputs with nonzero intrinsic quotient do not produce
additional Pareto points. `support_correspondence.md` proves that an
appropriate complement to their radical preserves the exact distance and
output, keeps the same length, and strictly decreases `S`.

Two outputs are identified when an invertible binary change of logical basis
relates their tensors. The remaining differences are diagonal Clifford
corrections, generated by S and CNOT conjugates of S (which include CZ).
Hadamards are not included in this equivalence.

An output's record contains the ordered basis taking the tensor of its
matrix witness to its displayed gate. Checking all triples of basis vectors
including repetitions proves the tensor identity, by trilinearity. The
displayed gates are heuristically simplified products of T, CS and CCZ;
minimal gate-factor count is not claimed.

For an independent construction of the displayed tensor, T on one variable
uses its single parity, CS on two variables uses their three nonzero
parities, and CCZ on three variables uses their seven nonzero parities.
The overlap parities of these columns give exactly the respective single,
pair or triple tensor entry. Signs of T rotations affect only diagonal
Clifford corrections and do not alter this binary tensor.

## Distinct outputs

The reference isomorphism check grows an ordered independent basis. At each
step it imposes all tensor entries whose arguments are already chosen.
The diagonal bit and rank of each contraction, including contractions by
linear combinations of the chosen vectors, are basis-independent filters.
Every genuine isomorphism passes these filters, so exhausting the finite
basis search proves inequivalence; a successful search supplies a basis
that can be checked directly. This is sufficient for the small output
dimensions of the distributed witnesses, independently of the production
canonicaliser.

## What this verifies

`code/verify_protocols.py` checks every witness's matrix conditions, intrinsic
output, displayed gate, exact distance, error coefficient and footprint.
It also checks pairwise output inequivalence and Pareto nondominance within
the supplied list. These checks alone do not prove that the list is complete.
That further claim requires the support enumeration, logical-subspace
coverage and theoretical dimension closure.
